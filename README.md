# controle-estoque-energia

## Descrição do Problema

Um técnico precisa organizar o estoque de baterias de um datacenter. O sistema deve receber a capacidade de cada bateria em mAh e o consumo estimado em mA. O objetivo é calcular o tempo de autonomia de cada uma e identificar qual bateria possui o menor tempo.

## Requisitos

- Calcular a autonomia em horas para cada bateria.
- Identificar a bateria com menor autonomia.
- Exibir o resultado de forma legível.

## Exemplo de Uso

Entrada:
[5000, 12000, 3000, 8000]
Consumo: 150

Saída:
Autonomia (horas): 33.33 | 80.0 | 20.0 | 53.33
Menor autonomia: 20.0 horas
